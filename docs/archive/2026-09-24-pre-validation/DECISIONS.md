# Lexicon Delver Decisions

Status: Authoritative
Version: 0.1
Date: 2026-09-24

## D-01: Lexicon Delver is the only active word-merge concept

Accepted.

Compound Forge and Chain Reaction are no longer active exploration targets.

They remain historical context only and must not be reintroduced unless explicitly requested.

## D-02: The game uses individual word components as tactical resources

Accepted.

A source word can participate in multiple possible combinations. Choosing one combination consumes that word and removes its other possible uses for the current encounter.

This opportunity cost is central to the concept.

## D-03: The merge system is semantic, not limited to strict dictionary compounds

Accepted for prototype testing.

Examples such as LIGHT SHIELD and BREAK ARMOR are allowed when the combined phrase communicates a coherent effect.

The design should not force every result to be a conventional one-word compound.

## D-04: Word meanings should communicate mechanical roles

Accepted.

Current semantic roles:

- FIRE: damage / burning / retaliation
- ICE: blocking / delay / stronger protection
- LIGHT: reveal / detection
- BREAK: removal of physical defense
- BALL: projectile form
- WALL: lane barrier form
- SHIELD: personal defense form
- ARMOR: durable protection or armor interaction

The player should be able to infer broad function from these meanings.

## D-05: Exact numbers may vary later, but semantic function must remain stable during validation

Accepted.

The prototype currently uses small fixed numbers only to make paper scenarios executable.

Do not rebalance or expand them before the first diagnostic test unless a scenario is impossible to run.

## D-06: The immediate validation question is not general fun

Accepted.

The primary question is:

"Does the word system create choices the player can reason about?"

Fun, progression appeal, marketability, visual polish, and long-term content volume are later questions.

## D-07: Five diagnostic scenarios replace the original ten-scenario Lexicon Delver set

Accepted.

Retained tests:
- LD-D1 One FIRE, Three Uses
- LD-D2 Shared Form Competition
- LD-D3 Multiple Valid Solutions
- LD-D4 Semantic Prediction
- LD-D5 Open Tactical Encounter

Earlier Lexicon Delver scenarios are historical test material and are not part of the current canonical diagnostic suite.

## D-08: Do not expand the game before validation

Accepted.

No new systems should be added until the five diagnostic scenarios are run and reviewed.
